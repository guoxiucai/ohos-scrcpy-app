用户手动切换视频分辨率或帧率后，需要**持久化存储**用户的选择，下次连接设备时**默认使用记忆的参数设置**，而不是每次都重置为初始值。

**实现思路**：
- 使用本地存储（如 `SharedPreferences`、`hive`、或简单的 JSON 文件）保存用户选择
- 连接设备时读取保存的参数作为默认值
- 用户手动修改参数后自动保存
